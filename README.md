The website should be designed so that it can later be converted into a mobile application using an app converter. Therefore, make the website mobile-friendly, responsive, easy to navigate, and suitable for both Android and desktop users.

10. M-PESA PAYMENT

Create a secure checkout/payment process.

After the customer confirms an order, display the M-Pesa payment instructions.

After making payment, provide an input field where the customer can enter their M-Pesa transaction code.

Example:

Enter M-Pesa Transaction Code:
[________________]

Add a Verify Payment button.

The system should verify the submitted M-Pesa code against the payment/order record.

Do not automatically mark an order as paid without successful verification.

Once the payment has been successfully verified, display:

"Thank you for shopping with us! Your package will be delivered soon."

The order should then be marked as Paid and sent to the admin dashboard for processing.
